## 结论摘要

- **有直接旧参照（high）**：Icon、Chart、Avatar、Captcha、SelectDialog、ErrorDetailDialog、ConfirmDialog、Dialog、Modal（Dialog 别名/壳）、Toast、Tooltip、FileTypeIcon、Card、OAuthAppCard、Pagination、Table。
- **旧参照不足（medium）**：DatePicker（旧项目只 import DateTimePicker，未用 DatePicker；日历/弹层数值取 MUI X v6.20.2 默认）、Graph（**完全无旧组件**，仅能按旧主题规范推导）、StatCard（旧项目无同名组件，取 Admin Home 统计卡 + AdminCard）、ImageCropper（只有头像裁剪弹窗 + 第三方 Filerobot 编辑器，无通用裁剪组件）。
- **需新设计但必须遵守的旧规范**：卡片/容器 = `background.paper + 1px divider + radius 12 + 无阴影`；标题 `subtitle1 16/1.75`（强调 500）或 `h6 20/1.6/500`；正文 `body2 14/1.43`；主色 `primary.main`；动效 250ms `cubic-bezier(0.4,0,0.2,1)`（短交互 150ms）；层级 Dialog 1300 < Toast 1400 < Tooltip 1500。
- **层级特例**：SearchPopup 1299（modal-1）；拖拽层 DragLayer 1600–1612（全站最高）；DropFile/ImageViewer/SplitHandle 用 drawer+1/+2（1201/1202）。

完整结构化数据（含每个组件的 oldSources/states/responsive/confidence）见同目录 `group-c.json`。
