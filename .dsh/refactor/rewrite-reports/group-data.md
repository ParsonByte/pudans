## 变更摘要

- 12 个组件全部改为 MUI 原语/主题 token 渲染：Table/TableContainer/TableHead/TableCell/TableRow、Pagination、Paper、Chip、Alert/AlertTitle、Avatar、Skeleton、LinearProgress/CircularProgress、Stepper/Step/StepLabel、recharts（主题化）、Paper/IconButton/Typography（graph 外壳）。
- 删除 10 个不再需要的自定义 CSS Module（alert/avatar/badge/card/stat-card/skeleton/progress/progress-steps/table/chart），仅保留 pagination（flex-end 结构）与 graph（SVG 画布结构）两个必要结构样式；全部色值/尺寸/动效引用 --pd-* token 或 MUI theme。
- 公开 API/类型未删除：所有现有 props（含兼容别名）与 forwardRef 保留；新增/透传 MUI 属性不破坏旧调用方。
- 遗留非本组 typecheck error 14 条均在其他 agent 负责目录，本组 0 error。
