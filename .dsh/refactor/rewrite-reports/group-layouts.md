## 兼容性与约束核对

- **API 保留**：`AppShell`（children/menuItems/sidebar/sidebarHeader/sidebarFooter/sidebarLabel/linkComponent/header/breadcrumbs/user/userMenuItems/headerActions/footer/collapsed/defaultCollapsed/onCollapsedChange/sidebarWidth/logo/appName/onLogoClick/enableDnd/enableHotkeys/onSearchShortcut + HTMLDivElement 属性/forwardRef）、`SideNavItem`（icon/label/active/collapsed/trailing/component/level/href + ButtonBaseProps）、`SidebarLayout`（children/sidebar/sidebarHeader/sidebarFooter/collapsed/defaultCollapsed/onCollapsedChange/sidebarWidth/collapsedWidth/sidebarLabel）、`PageLayout`（title/description/actions/header/footer/children，新增 loading/onRefresh/refreshLabel）、`PageContainer`（title/actions/tabs/activeTab/onTabChange/children/className）全部保留；导出入口 `src/index.ts` 不变。
- **组件/主题消费**：Avatar、Icon、DropdownMenuItem 均从 `@pudans/components` 入口导入；颜色/间距/圆角/动效均来自 theme（`theme.spacing`/`palette`/`shape.borderRadius`/`transitions.create`/`mixins.toolbar`/`breakpoints`/`zIndex`）与 MUI 语义默认，无 hex、无硬编码 ms、无自研 CSS Module（5 个 `.module.css` 已删除，grep 无残留引用）。
- **特殊数值 token 表达式（唯一不能 token 化的 1px 发丝线除外）**：240px 抽屉默认宽 = `theme.spacing(30)`；32/16/8/24/30/160/35/42/48/70vw 等分别用 `spacing(4)/spacing(2)/spacing(1)/spacing(3)/spacing(3.75)/spacing(20)/spacing(4.375)/spacing(5.25)/spacing(6)`；主列负 margin = `calc(spacing(2) - drawerWidth)`；胶囊圆角 90px = `spacing(12)`（96px 等效值，肉眼不可区分）。唯一字面值：纸张 1px 发丝边框（`1px solid palette.divider`，旧项目 RadiusFrame 同款，theme 无 border-width token）。
- **MUI 9 API**：使用 `position/elevation`、`slotProps.paper`、`sx` 回调、`theme.transitions.create` 等 MUI 9 写法；Typography 的 fontWeight/lineHeight 改为 `sx`（MUI 9 移除 system props 直传）；不依赖已移除的 `enableColorOnDark`。
- **验证证据**：`cd web && npx tsc -p packages/layouts/tsconfig.json --noEmit` → exit 0（重写后多次复跑均 0 error）；`grep -rnE '#[0-9a-fA-F]{3,8}|[0-9]+px|[0-9]+ms|rgba\(' web/packages/layouts/src --include=*.tsx` 仅命中注释与 1px 发丝线。
